# 心霊スポット放置記

▶ **遊ぶ：https://koppepandayooo.github.io/shinrei-spot-houchiki/**

銀髪ツインテールの探検家「ゆら」が、夜の心霊スポットを巡るドット絵の放置ゲームです。
HTML / CSS / JavaScript だけで動きます。ビルドは不要です。

## 遊び方

- ゆらは自動で探索を続け、**フィルム**が少しずつ貯まります
- 画面を**タップ（クリック）すると撮影**して、ボーナスのフィルムがもらえます
- ときどき現れる**幽霊が見えている間にタップすると「心霊写真」**が撮れて、大きなボーナスがもらえます
  - 幽霊は各スポットに2種類（うち1種は出にくいレア・ボーナス3倍）。撮った写真は「記録」タブのコレクションに並びます
- **装備**タブ：フィルムでアップグレードを買います。買うたびに値段が上がります（×1／×10／MAX のまとめ買いもできます）
  - 上位装備（お札・赤外線カメラ・霊感センサー）は、スポットを解放すると買えるようになります
  - 旧小峰トンネルまで進むと**お祓い**（転生。受けると最初からやり直す）ができます。装備やスポットは最初に戻りますが、「霊感」がたまり、すべての収入がずっと上がります
  - 懐中電灯：探索でもらえるフィルムが増える（25レベルごとに効果2倍）
  - カメラ：タップ撮影でもらえるフィルムが増える（25レベルごとに効果2倍）
  - 原付：探索スピードが上がる
  - お守り：放置で貯まる上限時間がのびる（初期8時間、1つにつき+2時間）
- **スポット**タブ：フィルムを払って次のスポットを解放します。奥のスポットほど報酬が大きく、収入（放置報酬・探索・撮影）は解放した中で一番高いスポットの倍率で計算されます（どのスポットにいても同じ）
  - まだ行けないスポットは、シルエットとヒントだけ見られます
  1. 八王子霊園の電話ボックス（×1）
  2. 陵北大橋（×3）
  3. 旧満地トンネル（×10）
  4. 道了堂跡（×35）
  5. 旧小峰トンネル（×120）
  6. 旧吹上隧道（×400）
  7. 八王子城跡（×1,400）… 探索中に御主殿の滝の前を通ると、ゆらが静かに手を合わせます
  8. ？？？（隠しスポット。ある条件を満たすと現れます）
  - 並びは「全国心霊マップ」の順位を参考にした弱い順です。背景は実物の写真・資料を確認して描いています
- セーブはブラウザの localStorage に自動で保存されます（5秒ごと、タブを閉じたときなど）
- ページを閉じていた間も、次に開いたときに経過時間ぶんのフィルムがまとめてもらえます（**5分以上閉じていたときだけ**。タブを切り替えて裏に回しただけでは付きません。裏にある間は探索も止まります）
- **仲間**タブ：黒猫のクロ（ときどきフィルムを拾ってくる）、オカルト好きの後輩ミオ（撮影ボーナス）、ベテラン探検家ゲンさん（探索収入アップ）。画面のゆらのまわりに表示されます
- **デイリーボーナス**：1日1回、開くとフィルムがもらえます。連続日数で増え、7日目は大きめ＋霊感+1（端末の日付で判定）
- **ランキング**：名前を登録すると自動でスコアが送られ、オンラインランキングに載ります。スコアは「ランキングのリセット後に獲得したフィルム」です（サーバーの準備・リセットの手順は `worker/README.md`）
- **足音イベント**：ときどき「……足音が聞こえる」と表示され、「逃げる」「撮る」を選べます。「撮る」は確率で大ボーナス、失敗するとフィルムを少し失います。「逃げる」と何も起きません
- **現実の時刻・天気との連動**：日本時間の時刻に合わせて、外のスポットは昼・夕方（明け方）・夜に切り替わります（トンネルの中はいつも暗いまま）。各スポットのあたりの現実の天気（晴れ・くもり・霧・雨・雪・雷雨）も画面に出ます。天気は30分に1回、[Open-Meteo](https://open-meteo.com/) から取得します（APIキー不要・位置情報は使いません）
  - 夜は心霊写真が少し出やすく（+15%）、夕方・明け方の「逢魔が時」はさらに出やすく（+25%）なります
  - 雨の日は心霊写真が出やすく（+20%）、**雨の日だけの心霊写真**（2種）が出ることがあります。足音イベントの「撮る」の成功ボーナスも1.5倍です。雷雨の日はときどき雷が光って鳴ります
  - 雨の日だけの写真は、隠しスポットの条件には入っていません
  - 天気が取れないときは天気なし（いつもの表示）になり、時間帯だけ端末の時計で切り替わります。設定でオフにすると、これまでどおりの「いつもの夜」になります
- **チャット**：ランキングの横（スマホではランキングの下）で、遊んでいる人どうしで話せます（ランキングの名前の登録が必要。80文字まで・7日で消える）
- **ご意見・不具合の報告**：設定画面から開発者に送れます（ほかのプレイヤーには見えません。読み方は `worker/README.md`）
- **実績**：条件を満たすと画面右下に通知が出ます。「記録」タブで一覧を見られます
- **セーブコード**：「記録」タブの「書き出す」で、セーブデータを文字列としてコピーできます。別のブラウザやスマホで「読み込む」に貼り付けると続きから遊べます（サーバー不要）

## ファイル構成

```
心霊スポット放置記/
├── index.html      … 画面の骨組み
├── css/
│   └── style.css   … 見た目（ダークテーマ・レスポンシブ）
├── js/
│   ├── config.js   … ランキングの URL などの設定
│   ├── updates.js  … バージョン番号とアップデート情報の文章（更新したらここを書き換える）
│   ├── data.js     … スポット・アップグレード・セリフなどのデータ（バランス調整はここ）
│   ├── sprites.js  … ドット絵。ゆら（64x64）はパーツごとに描いて輪郭線をつける方式、幽霊・アイコンは文字のピクセルマップ
│   ├── scene.js    … 背景・ランドマーク・暗闇と懐中電灯の光、スポット一覧のサムネイル
│   ├── backdrop.js … PCで広げたときに左右を埋める夜空と山並みの背景
│   ├── sound.js    … 効果音と環境音（WebAudioで合成。音声ファイルなし）
│   ├── weather.js  … 現実の時刻（日の出・日の入り）と天気の取得（Open-Meteo）
│   ├── realworld.js … 時刻・天気をゲームに反映（表示・心霊写真の出やすさ・雷など）
│   ├── chat.js     … チャットと、開発者への意見・不具合の報告
│   ├── extras.js   … 仲間・お祓い（転生）・音量・デイリーボーナス・ランキング
│   └── game.js     … ゲームの状態、計算式、セーブ、実績、足音イベント、UI、メインループ
├── img/
│   ├── yura_pixel.png … ゆらのドット絵（yura.png から自動生成）
│   ├── comp_cat.png / comp_kohai.png / comp_vet.png … 仲間のドット絵（元イラストから自動生成）
│   ├── favicon-32.png / favicon-16.png … タブのアイコン
│   └── apple-touch-icon.png … iPhone/iPad のホーム画面アイコン
├── tools/          … ※手元のみ（このリポジトリには含めていません）
│   ├── pixelize.py … yura.png → img/yura_pixel.png の変換スクリプト
│   └── make_icons.py … yura_pixel.png からアイコンを作るスクリプト
├── favicon.ico     … タブのアイコン（古いブラウザ向け）
├── yura.png        … ゆらの元イラスト ※手元のみ（このリポジトリには含めていません）
├── worker/         … ランキング API（Cloudflare Workers + D1。手順は worker/README.md）
└── README.md
```

ゆらは `img/yura_pixel.png` を使い、背景・幽霊・アイコンは `sprites.js` / `scene.js` のコードで描画しています。
画像が読み込めないときは、コードで描いた予備のゆらが表示されます。

### ゆらの画像を差し替えるとき

（手元の作業フォルダでの作業です）`yura.png` を置き換えてから、次のコマンドでドット絵を作り直します（Python と Pillow・numpy が必要）。

```bash
python tools/pixelize.py
```

縦のサイズや色数は `--height 96 --colors 32` のように変えられます。
アイコンも作り直すときは、続けて `python tools/make_icons.py` を実行してください。

仲間のドット絵は次のコマンドで作り直せます（元イラストは手元のみ）。

```bash
python tools/pixelize.py --src koppecat.jpg --out img/comp_cat.png --height 38 --colors 16 --outline "#5a5280"
python tools/pixelize.py --src kouhai2.png --out img/comp_kohai.png --height 86 --colors 32
python tools/pixelize.py --src veteran.png --out img/comp_vet.png --height 92 --colors 32
```
（フォントだけ Google Fonts の「DotGothic16」を読み込んでいます。オフラインでも等幅フォントで動きます）

## ローカルで遊ぶ

`index.html` をブラウザにドラッグ＆ドロップするだけで動きます。

## GitHub Pages で公開する手順

### ブラウザだけでやる方法（かんたん）

1. GitHub にログインし、右上の「＋」→「New repository」
2. リポジトリ名を入力（例：`shinrei-houchi`）、**Public** を選んで「Create repository」
3. 作成後の画面で「uploading an existing file」をクリック
4. このフォルダの中身（`index.html`、`favicon.ico`、`css`・`js`・`img` フォルダ、`README.md`）をまとめてドラッグ＆ドロップし、「Commit changes」
   - `yura.png` と `tools` フォルダは公開に必要ありません（置いても問題はありません）
   - ※フォルダごとではなく、**中身**を置いてください。`index.html` がリポジトリの一番上にある状態にします
5. リポジトリの「Settings」→ 左メニュー「Pages」
6. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main** / **/(root)** にして「Save」
7. 1〜2分待つと、同じページの上部に公開URLが表示されます
   - `https://<ユーザー名>.github.io/shinrei-houchi/`

### git コマンドでやる方法

```bash
cd 心霊スポット放置記
git init
git add .
git commit -m "最初のバージョン"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/shinrei-houchi.git
git push -u origin main
```

そのあと、上の手順 5〜7 で Pages を有効にします。

### 更新するとき

`index.html` で読み込んでいる CSS・JavaScript には `?v=20261121-6` のような番号が付いています。ファイルを更新したら、この番号をすべて新しい値（日付など）に変えてください。古いファイルがブラウザに残っていて、新旧が混ざって動かなくなるのを防ぎます。

ファイルを書き換えて、もう一度アップロード（または `git push`）するだけです。数分で反映されます。
反映されないときはブラウザでスーパーリロード（Ctrl+Shift+R / スマホはタブを開き直す）してください。

## 注意

- セーブデータは「ブラウザごと・URLごと」に保存されます。別の端末やブラウザへはセーブコードで引っ越してください
- ブラウザのデータ（サイトデータ）を消すとセーブも消えます
- ゲーム内の怪奇現象はすべてフィクションです。実在のスポットを訪れる際は、私有地・立入禁止区域に入らず、地域の方の迷惑にならないようにしましょう

### 天気データ：Open-Meteo

現実の天気との連動には [Open-Meteo](https://open-meteo.com/) の Forecast API を使っています。

- 天気データは **[Weather data by Open-Meteo.com](https://open-meteo.com/)**、ライセンスは **[クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/deed.ja)** です
- 変更点：取得したデータ（天気コード・降水量・雲量・日の出／日の入り）を、ゲームの背景の明るさや雨・雪・霧などの演出、ゲーム内の効果に変換して使っています（画面に出す数値は日の出・日の入りの時刻だけです）
- Open-Meteo がこのゲームを推奨・保証しているわけではありません
- Open-Meteo のデータは、各国の気象機関の予報モデルをもとにしています（日本付近は気象庁［[JMA](https://www.jma.go.jp/)］のモデルなど。詳しくは [Open-Meteo のライセンスページ](https://open-meteo.com/en/licence)）
- 無料の API は**非営利での利用に限られます**（[利用規約](https://open-meteo.com/en/terms)）。このゲームに広告やサブスクリプションを入れる場合は、商用プランへの切り替えが必要です。無料枠の目安は1日1万回・1時間5,000回・1分600回までです（このゲームは、各プレイヤーのブラウザから30分に1回、全スポット分をまとめて取得します）
- ゲーム画面の左上（天気の表示のすぐ下）と設定画面に、出典のリンクを表示しています
